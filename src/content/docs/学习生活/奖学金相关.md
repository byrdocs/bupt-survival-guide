---
title: 奖学金相关
---

本节介绍北京邮电大学奖学金的类别、奖励金额、评审流程及申请要求

:::note
学校奖学金制度涉及多个管理文件，各学院的具体评审标准可能存在差异。涉及排名要求、名额分配及申请流程的内容，请以学校及学院当年度发布的正式通知为准
:::

## 奖学金类别

北邮奖学金主要包括以下类别：

- **国家奖学金**：本科生国家奖学金、研究生国家奖学金
- **国家励志奖学金**：面向品学兼优的家庭经济困难本科生
- **本科优秀学生奖学金**：包括一等奖学金（甲奖）、二等奖学金（乙奖）、三等奖学金（丙奖）
- **研究生学业奖学金**：按照研究生培养阶段及相应评审要求设置
- **单项奖学金**：包括国防奖学金等
- **社会捐赠奖学金**：由企业、社会组织或个人捐赠设立，例如华为、小米、招商银行、比亚迪等相关奖学金，具体以当年实际设立的项目为准
- **“双培计划”学生奖学金**：面向符合条件的“双培计划”学生
- **其他专设奖学金**：包括政府部门和社会组织面向特定群体设置的奖学金

## 奖学金金额

以下列出相关奖学金的奖励金额，具体以当年度政策为准。[^1][^2][^3][^4]

| 奖学金类型 | 奖励金额 |
| --- | ---: |
| 本科生国家奖学金 | 10,000 元/人/年 |
| 硕士研究生国家奖学金 | 20,000 元/人/年 |
| 博士研究生国家奖学金 | 30,000 元/人/年 |
| 国家励志奖学金 | 6,000 元/人/年 |
| 本科优秀学生一等奖学金（甲奖） | 5,000 元/人/年 |
| 本科优秀学生二等奖学金（乙奖） | 3,000 元/人/年 |
| 本科优秀学生三等奖学金（丙奖） | 1,000 元/人/年 |

社会捐赠奖学金一般为 5,000～20,000 元，具体金额根据捐赠协议及当年度奖学金设置确定。部分企业奖学金的具体信息可以在学工系统的「奖学金」栏目中查询。[^1]

## 评审程序[^2]

1. **发布通知**：学校根据当年度评奖评优工作安排，按照各学院参评学生规模制定名额分配方案
2. **学院评审**：各学院成立相应的学生奖助工作领导小组及评审委员会，按照申请、资格审查、民主评议等程序确定拟推荐名单，并在学院范围内公示不少于 5 个工作日。公示无异议并经学院审议后，上报学校
3. **学校审定**：学校根据各学院报送的名单组织评审，确定拟获奖名单，并在全校范围内公示不少于 5 个工作日
4. **结果备案与发放**：公示无异议后，完成相关备案及奖励发放工作

对于评审结果存在异议的学生，可以在学院或学校公示阶段，按照规定提出申诉

## 部分奖学金申请要求

不同类型的奖学金适用不同的评审细则，以下分别介绍本科生国家奖学金、本科优秀学生奖学金及社会捐赠奖学金的相关申请要求

### 本科生国家奖学金

根据《北京邮电大学本科生国家奖学金评审实施细则》[^3]，申请者除满足遵纪守法、诚实守信、学习成绩优异等基本条件外，还应满足以下要求：

- **年级要求**：本科二年级及以上学生
- **成绩要求**：学习成绩排名与综合素质评价成绩排名均位于前 10%（含 10%）
- **特殊情况**：学习成绩排名和综合素质评价成绩排名未进入前 10%，但均达到前 30%（含 30%）的学生，如在其他方面表现特别突出，也可以申请，但需要提交经学校相关部门审核的证明材料

有下列情况之一的学生，不具备参评资格：

- 违反国家法律、校纪校规受到纪律处分
- 存在抄袭剽窃、弄虚作假等学术不端行为
- 参评时学籍处于休学状态
- 无正当理由不按时缴纳学费、住宿费
- 参评学年有课程考试不及格

各学院负责制定本学院的具体评审细则，实际名额及评审安排以当年度通知为准

### 本科优秀学生奖学金

根据《北京邮电大学本科优秀学生奖学金评审实施细则》[^2]，本科优秀学生奖学金主要依据[综合素质评价](/学习生活/成绩构成/#综合素质评价)结果进行评选

#### 基本申请条件

以下条件适用于申请本科优秀学生奖学金的学生：

- **年级要求**：本科二年级及以上学生
- **思想品德要求**：遵守宪法和法律、学校规章制度，诚实守信，道德品质优良
- **综合表现要求**：学习成绩优异，综合素质优秀，在社会工作、创新实践、志愿服务等方面表现突出
- **纪律与成绩要求**：参评学年至参评期间无违纪行为、无考试不及格、无故意欠缴学费和住宿费情况

#### 评选比例

按照学校公布的评选比例：

| 奖项 | 获奖人数占参评人数比例 |
| --- | ---: |
| 一等奖学金（甲奖） | 3% |
| 二等奖学金（乙奖） | 10% |
| 三等奖学金（丙奖） | 25% |

以上为学校规定的获奖人数比例，不代表达到相应专业排名即可获得奖学金

各学院负责制定本学院的具体评定细则，实际评选结果以当年度评审及公示为准

### 企业及其他社会捐赠奖学金

根据《北京邮电大学学生奖助工作管理办法》[^1]，社会捐赠奖学金由企业、社会组织或个人捐赠设立，不同奖项的申请条件、奖励金额及评选名额可能存在差异

学生可以通过学校学工系统中的「奖学金」栏目查询具体奖项及申请要求

如需调整申请奖项，可以联系辅导员或相关负责老师，确认是否允许放弃原有奖学金名额并申请其他奖项，具体以当年度评审安排为准

:::caution
不同奖学金之间可能存在兼得限制。本科生国家奖学金和本科优秀学生奖学金均有相应的兼得规定，即以上三种奖学金只能选取一种获得。具体以各自评审细则为准[^2][^3]
:::
