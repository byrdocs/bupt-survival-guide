title: 奖学金相关
---

本节介绍北京邮电大学奖学金的类别、奖励金额、评审流程及部分申请经验

:::note
由于学校奖学金制度涉及多个管理文件，且各学院的具体评审标准存在差异，以下内容综合学校官方文件及笔者个人参与评奖评优的经历整理

涉及学院排名要求、名额分配及具体申请流程的内容可能随学年调整，**请以学校及学院当年度发布的正式通知为准**
:::

## 奖学金类别

北邮奖学金主要包括以下类别：

- **国家奖学金**：本科生国家奖学金、研究生国家奖学金
- **国家励志奖学金**：面向品学兼优的家庭经济困难本科生
- **本科优秀学生奖学金**：包括一等奖学金（甲奖）、二等奖学金（乙奖）、三等奖学金（丙奖）
- **研究生学业奖学金**：按照研究生培养阶段及相应评审要求设置
- **单项奖学金**：包括国防奖学金等
- **社会捐赠奖学金**：由企业、社会组织或个人捐赠设立，例如华为、小米、招商银行、比亚迪等相关奖学金，具体以当年实际设立的项目为准
- **“双培计划”学生奖学金**：面向符合条件的“双培计划”学生
- **其他专设奖学金**：包括政府部门和社会组织面向特定群体设置的奖学金

此外，学校还设置优秀研究生、优秀研究生干部、文体活动积极分子、先进班集体、优秀学生宿舍等荣誉奖励。需要注意，**荣誉奖励与奖学金并不完全相同**

## 奖学金金额

以下列出相关奖学金的奖励金额，具体以当年度政策为准。

| 奖学金类型 | 奖励金额 |
| --- | ---: |
| 本科生国家奖学金 | 10,000 元/人/年 |
| 硕士研究生国家奖学金 | 20,000 元/人/年 |
| 博士研究生国家奖学金 | 30,000 元/人/年 |
| 国家励志奖学金 | 6,000 元/人/年 |
| 本科优秀学生一等奖学金（甲奖） | 5,000 元/人/年 |
| 本科优秀学生二等奖学金（乙奖） | 3,000 元/人/年 |
| 本科优秀学生三等奖学金（丙奖） | 1,000 元/人/年 |

本科优秀学生一等奖学金此前的奖励标准为 8,000 元，现已调整为 5,000 元

社会捐赠奖学金一般为 5,000～20,000 元，具体金额根据捐赠协议及当年度奖学金设置确定。部分企业奖学金的具体信息可以在学工系统的「奖学金」栏目中查询

更多信息可参见[北京邮电大学学生奖助工作管理办法](https://xsc.bupt.edu.cn/info/1065/1493.htm)

## 评审程序

各类奖学金的具体评审流程可能存在差别。以本科优秀学生奖学金为例：

1. **发布通知**：学校根据当年度评奖评优工作安排，按照各学院参评学生规模制定名额分配方案
2. **学院评审**：各学院成立相应的学生奖助工作领导小组及评审委员会，按照申请、资格审查、民主评议等程序确定拟推荐名单，并在学院范围内公示不少于 5 个工作日。公示无异议并经学院审议后，上报学校
3. **学校审定**：学校根据各学院报送的名单组织评审，确定拟获奖名单，并在全校范围内公示不少于 5 个工作日
4. **结果备案与发放**：公示无异议后，完成相关备案及奖励发放工作

对于评审结果存在异议的学生，可以在学院或学校公示阶段，按照规定提出申诉

## 部分奖学金硬性要求

以计算机学院为例，不同学院请参见各种学院具体要求

### 国家奖学金

智育成绩在全专业10%以内，综测成绩在全专业10%以内，满足以上两条才有资格进入面试答辩，但是约定俗成只取全专业人数的2%也就是进入面试的人的前20%，故基本综测出来即可确定你是否由国家奖学金

### 本科优秀学生奖学金

本科优秀学生奖学金主要依据[综合素质评价](/学习生活/成绩构成/#综合素质评价)结果进行评选
校奖只看综测成绩，不关注智育成绩，其中按照学校公布的评选比例：
| 奖项 | 获奖人数占参评人数比例 |
| --- | ---: |
| 一等奖学金（甲奖） | 3% |
| 二等奖学金（乙奖） | 10% |
| 三等奖学金（丙奖） | 25% |

### 企业及其他社会捐赠奖学金

企业奖学金通常由企业或其他捐赠方设立，具体申请条件、奖励金额及评选名额可能存在差异。学生可以通过学校学工系统中的「奖学金」栏目查询具体奖项及申请要求

在部分奖学金名单初步确定与正式填报之间，存在一段调整申请奖项的时间。在此期间，学生可以主动联系辅导员或相关负责老师，咨询是否能够放弃已经获得或拟获得的国家奖学金、学校奖学金名额，转而申请符合条件的企业奖学金

### 所有奖学金奖学金基本申请条件

根据《北京邮电大学本科优秀学生奖学金评审实施细则》，所有奖学金的申请都需要需要满足相应的基本条件，包括：

- 本科二年级及以上学生。
- 参评学年至参评期间无考试不及格情况
- 无违纪行为
- 无故意欠缴学费、住宿费情况
- 满足学校规定的其他思想品德、学业成绩及综合素质要求

具体条件以当年度官方文件为准

:::caution
1.以上奖学金只能获取一种中的一个，不可以同时获取多个，以本科优秀学生奖学金为例，根据学校规定，同一学年获得该奖学金的学生，原则上不能同时获得其他奖学金，但荣誉奖励、政府部门和社会组织专设奖学金等存在规定的例外。
2.在部分评审情况下，放弃的名额可能根据学院安排递补给其他符合条件的学生，具体查看当年实施政策
:::
